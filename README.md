# Voyora — Hotel & Travel Booking Website

A responsive multi-page hotel discovery and travel booking website concept built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home page, destination discovery, hotel highlights and search form
- `hotels.html` — Hotel listing with keyword and price filters
- `hotel-details.html` — Dynamic hotel detail page and booking request form
- `destinations.html` — Destination discovery gallery
- `about.html` — Brand story and values
- `contact.html` — Contact form demo

## Features
- Responsive desktop, tablet and mobile layouts
- Mobile navigation
- Destination search and hotel filtering
- Dynamic hotel detail content through URL parameters
- Date input validation and booking request interaction
- Contact and newsletter form demo interactions
- SEO page titles and meta descriptions
- Google Fonts and Unsplash photography

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Important
This is a front-end portfolio project. Booking, contact and newsletter forms only show demo confirmation messages. They do not create real reservations, process payments, send emails or store submissions. A production launch requires a backend, database, email integration, secure payment provider and real hotel inventory/availability API.

## Customize
Update hotel data in `assets/js/main.js`, hotel cards in `hotels.html`, image URLs, contact details and styles in `assets/css/style.css`.
